# AMBA APB Interface & Handshake Protocol

RTL implementation and simulation of an AMBA Advanced Peripheral Bus (APB) Master/Slave protocol interface using Verilog HDL and Logisim schematics.

## Key Features
- **FSM-Based Control:** State machine handling `PSEL` and `PENABLE` control logic.
- **Protocol Verification:** Testbench environment simulating read/write operations with `handshake.vcd` waveform inspection.
- **Gate-Level Schematics:** Complete Logisim circuit modeling signal handshaking.

## Tools Used
- Verilog HDL
- Logisim
- GTKWave / QuestaSim
